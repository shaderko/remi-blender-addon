# Remi 2.7.0-beta.1 — model generation beta

This prerelease contains the model-generation work on the `model-generation`
branch. It does not replace the stable `main` branch or stable GitHub release.
Back up your project files before trying experimental tools.

## Included

- Local image-to-Gaussian-splats generation with the `rand6_100_ncm` model.
- Native Gaussian point clouds when supported by Blender 5.3; an ellipsoid
  preview fallback for Blender 5.1/5.2.
- Gaussian-to-mesh reconstruction and the reconstructed-mesh optimization preset.
- A Texture workspace with viewport projection, lasso-defined regions, layered
  views and rendered Gaussian normal maps.
- A configurable warm-worker cache for repeated local generations.
- On-demand model downloads from Hetzner, with progress, cancellation,
  SHA-256 verification, atomic installation and interrupted-transfer recovery.

## Install and download models

1. Download the extension ZIP matching your platform from this beta release.
2. In Blender, use **Preferences → Get Extensions → Install from Disk** and enable Remi.
3. Enable **Allow Online Access** in Blender Preferences when downloading models.
4. Open **Remi → Generate → gear**, choose a writable **Model Folder** outside
   the extension directory, and click **Download Models**.

The release ZIP contains **no model weights**. The default download is about
4.52 GB and uses the same immutable step-1500 checkpoint as Remi's WebGPU website:

```text
Model: rand6_100_ncm
Checkpoint step: 1500
SHA-256: af36bcb6f84fdd5f71eb16247b53fba6cb953c05a11033f5e683b27bee721676
Release: triposplat-rand6_100_ncm-step1500-af36bcb6-v1
```

Existing verified files are reused. Existing conflicting weights are not
overwritten; choose a new empty folder when testing downloads. Cancelling
removes this job's partial downloads, not your existing weights or results.
Saved `.blend` files can retain their own Model Folder setting.

## Requirements and limits

- Generation requires an **external CUDA/PyTorch Python environment** and an
  NVIDIA GPU with bfloat16 support. Blender does not run these weights on WebGPU.
- Images and inference stay local; Hetzner only hosts downloadable model files.
- Blender 5.3 native Gaussian rendering has been tested locally. This does not
  qualify every remeshing, UV or baking operation for every Blender 5.3 beta build.
- Reconstructed meshes are a lossy approximation of Gaussian splats, not a
  faithful native Gaussian render.
- Experimental generation and texturing should be reviewed on copies of projects.

See [image generation](../image_generation.md) and
[texture projection](../texture_projection.md) for detailed setup and usage.
