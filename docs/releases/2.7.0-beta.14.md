# Remi 2.7.0-beta.14 — Shared Cloud projects

## Projects and collaboration

- Sign in with the same Remi account used on the web, then choose a personal or
  team project from the board header. A separate Local board remains available.
- Create projects and teams, invite teammates, and manage team access in Blender.
- Share uploaded and generated assets, card positions, connections and deletions
  through live WebSocket updates. Pending edits are kept locally while reconnecting.
- Import selected Blender meshes or native Gaussian objects into the shared board.
- Apply to Card updates the same shared mesh card. Conflicting edits from another
  device preserve the newer shared revision and keep the local file.
- Personal storage and each team's separate 1 GiB allowance use Cloud accounting.

## Board and account improvements

- Unified board settings and a centered browser-approval sign-in dialog.
- Consistent board sizing and pointer interactions across display scales.
- Cloud errors distinguish storage, concurrency and request limits.
- Generation recovery retains the original request and project identity.

## Scope and installation

Requires Blender 5.3. Install the ZIP matching your operating system through
Preferences → Get Extensions → Install from Disk, then enable Remi. Restart
Blender after replacing an older build.

Scene objects and their transforms do not synchronize. Import into the board and
Add to Scene are explicit actions. Native editable `.blend` snapshots remain
local; shared meshes use self-contained GLBs and Gaussians use lossless REMIGAUS
files. The original scene is preserved.

Cloud features require the project/device API deployed by remi-cloud-app commit
`f12ab0e` or later. Local generation still requires its configured external runtime
and model downloads; model weights are not included in these packages.

This is a prerelease. The published packages are accompanied by SHA-256 checksums.
