# Remi 2.7.0-beta.15 — Local Codex images and reference context

## Image generation

- Choose **Codex (experimental)** in Image generation settings, enable Blender's
  **Allow Online Access**, and click **Continue with ChatGPT**. The connection
  lasts for the current Blender session; Disconnect ChatGPT forgets it.
- Generate images using the normal board composer. No separate Python, Node,
  Codex CLI, API key, or local model download is needed for this provider.
- Select ready image cards to provide context. Numbered thumbnails show their
  order and the composer shows the context count. Up to 16 PNG/JPEG/WebP images,
  totaling 20 MiB, are accepted. Deselect all images for text-only generation.
- Queued requests retain their original references. Missing or changed inputs
  produce an explicit error; every image in a batch uses the same frozen inputs.
- Generated images synchronize to the selected personal or team project through
  the existing Cloud board connection. Results link to their first reference.
  Local boards keep generated images local; Blender scene transforms do not sync.
- Quality, requested size, and batch count are available. Actual returned image
  dimensions are recorded because the native endpoint may choose another size.
  3D generation keeps its independent Remi Local/Cloud backend.

## Fixes

- Cloud asset downloads work through the public Cloud edge.
- Completed local images enter an open shared board and its upload queue.
- Batch generation preserves the next queued prompt's placeholder.
- Project switching is blocked during generation. Results from an old board or
  account stay local rather than entering another project's board.
- Settings actions show expected failures inline instead of raising a traceback.
- ChatGPT settings expose Blender's online-access preference. Embedded Python
  loads trusted host certificates without disabling TLS verification.

## Installation and experimental access

Requires **Blender 5.3**. Install the ZIP matching your platform through
Preferences → Get Extensions → Install from Disk, then enable Remi. Restart
Blender after replacing an older build. SHA-256 checksums accompany the packages.

Codex image access is experimental. This local integration uses the native Codex
image endpoint and public Codex browser registration. OpenAI's documented
third-party Sign in with ChatGPT flow currently excludes image generation;
being local and open source does not establish supported third-party image access.
Availability depends on the account and may change. See
[OpenAI preview limitations](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations).

ChatGPT tokens stay in the local worker's memory and are not sent to Remi Cloud
or stored in project files. Completed image files use normal project storage.
Canceling an in-flight request does not guarantee cancellation or refund upstream.
Local Iris and 3D tools retain their existing runtime/model requirements.

## Validation

Release checks cover both platform packages, archive contents, and clean-profile
installed-extension smoke tests. Reference tests verify ordered image bytes,
image-edit requests, queue isolation, and missing/changed-input handling using
synthetic model responses. A real disposable team backend verified a member's
reference download, the linked result upload, and WebSocket movement/deletion.
Automated checks do not sign into a real ChatGPT account or spend plan usage.
