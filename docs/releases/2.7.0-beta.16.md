# Remi 2.7.0-beta.16 — Windows cache fixes, IDOL and remembered sign-in

## Windows shared assets

- Shorter content-addressed cache filenames avoid the Windows path-length failure
  that could prevent shared image previews and Gaussian source files from loading.
- Full file size and SHA-256 verification remain enabled. Existing project scopes,
  pending uploads and recovery records are preserved; missing assets redownload.

## Remembered sign-in

- Remi Cloud and ChatGPT sign-in persist across Blender restarts and file loads.
- Sign in once after updating from beta.15. Later starts restore the saved account
  with Online Access enabled. Remi sessions are checked with the original server.
- macOS uses login Keychain; Windows uses user-bound DPAPI encryption. There is no
  plaintext token fallback, and credentials never enter .blend files or logs.
- Normal shutdown no longer revokes the Remi session. Explicit Sign Out removes
  its saved login and attempts server revocation. Disconnect ChatGPT removes its
  saved local connection. Expired or revoked credentials require sign-in again.
- ChatGPT refresh-token updates are serialized across Blender processes. Temporary
  network failures preserve the saved login.

## 3D engines

- Generate 3D now offers **IDOL · Local**, **IDOL · Cloud**, **NCM · Local**, and
  the existing **TripoSplat · Local** compatibility option.
- Fresh shared projects default to IDOL Cloud. An explicit local engine choice
  survives project changes and does not switch the image provider.
- Cloud generation checks the server's advertised model instead of assuming NCM.
  NCM remains local-only. Local results still synchronize to the selected project.
- IDOL Local uses the pinned SDK and weights shared with Cloud, with a default
  20-step budget. Download Models verifies and reuses shared encoder files.
- IDOL Local requires an external CUDA/PyTorch environment with bfloat16 support
  and the additional dependencies in `integrations/idol/requirements.txt`. Eager
  execution avoids requiring a local compiler. Model weights are not bundled.

## Installation and testing

Requires Blender 5.3. Install the ZIP matching your operating system through
Preferences → Get Extensions → Install from Disk, then restart Blender.
SHA-256 checksums accompany both packages.

For the Windows retest: sign in, open an existing shared project, check image
previews and generate IDOL Cloud Gaussians. Restart Blender and confirm the saved
login restores. Sign Out should prevent restoration on the next start.

Validation covers package integrity, clean installed-extension smoke tests,
Windows path-limit reproduction, engine routing, pinned IDOL downloads and
synthetic output arrays, native credential-store round trips, owned-worker
restart restoration, logout/revocation and refresh rotation. Automated tests use
synthetic accounts and model responses. Real local IDOL GPU inference and the
reported customer Windows workflow still need interactive testing.

Codex image access remains experimental; see the
[beta.15 access notes](https://github.com/shaderko/remi-blender-addon/releases/tag/v2.7.0-beta.15).
