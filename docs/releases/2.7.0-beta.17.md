# Remi 2.7.0-beta.17 — Cloud Gaussian mesh and texture fixes

Mesh reconstruction and texture projection now accept native Cloud `REMIGAUS`
splats as well as local numeric NPZ archives. Previously, these workers tried to
open Cloud splats with NumPy's NPZ loader, producing the misleading error
“This file contains pickled (object) data.”

- Both workers use Remi's format-aware decoder and validate numeric arrays,
  dimensions, Gaussian counts, file lengths and archive-size limits.
- Pickle loading remains disabled. Object arrays and malformed inputs remain
  rejected; older numeric-only worker NPZ archives stay compatible.
- Existing shared splats can be reused; generating them again is unnecessary.
- Includes beta.16's Windows cache-path fixes, remembered sign-in and IDOL engines.

Requires Blender 5.3. Install the ZIP for your operating system through
Preferences → Get Extensions → Install from Disk, then restart Blender.
SHA-256 checksums accompany both packages.

For the Windows retest, open an existing Cloud Gaussian card and run mesh
reconstruction, then project its appearance onto the mesh. Also check local NPZ
splats. No unsafe-load setting or pickle permission is needed.

Validation includes native Cloud and local numeric archive compatibility,
rejection of object arrays and malformed inputs, real mesh extraction using the
pinned remi-splat-mesh backend, subprocess texture generation and Blender mesh
and texture regression checks. Windows and macOS CI build and validate clean
installed extensions before publication.
