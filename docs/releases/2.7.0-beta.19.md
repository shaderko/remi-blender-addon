# Remi 2.7.0-beta.19 — Adaptive Meshes and Compressed Cloud Downloads

- Create Mesh uses the shared adaptive Gaussian mesher. Sparse regions use a
  coarser surface where topology checks pass, while dense or ambiguous regions
  retain fine detail.
- Native contour assembly uses fewer temporary allocations. The validated
  lantern output remains byte-identical after the performance changes.
- Cloud downloads support lossless compression for generated and shared assets.
  The local lantern benchmark reduced Gaussian transfers by 23% and mesh
  transfers by 29%; savings vary by file. Compression is skipped when savings
  are below 5%.
- The add-on restores original file bytes and verifies their size and SHA-256
  before import. Older servers continue to work through the raw-file fallback.

Requires Blender 5.3 or newer. Install the ZIP matching your operating system,
then restart Blender. Generation quality and original downloaded file contents
are unchanged by compression.
