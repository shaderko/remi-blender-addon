# 2.7.0-beta.2 — camera-aware Create Mesh

Local prerelease; not a replacement for the stable mesh-tools release.

- Replace Create Mesh's density/Surface Nets backend with camera-aware opacity
  extraction and training-silhouette constraints.
- **Dense · Surface Optimized** is the default; **Fast · Direct Surface** skips
  fitting. Both preserve dense detail and vertex colors without automatic
  smoothing, simplification, hole filling, or size-based component deletion.
- Read the active object's Gaussian data even after its original archive is
  deleted; preserve source/result linkage and object transforms.
- Run rendering and reconstruction outside Blender with stage progress, logs,
  source/raw/constrained artifacts, and owned process-tree cancellation.
- Install the optional checksum-pinned Spirula tool through an explicit,
  online-access-gated download. It is GPL-3.0 and not bundled in this ZIP.

**Create Mesh requirements:** Blender 5.3+ native Gaussian rendering, Windows
x64, Vulkan GPU, and external Python with numpy/scipy/Pillow/trimesh/torch.
Other Remi features retain their own compatibility requirements.

The local ship worker test produced about 3.5M vertices / 7M triangles in 162 s
(Dense), or 472k vertices / 943k triangles in 32 s (Fast). These are one-asset
timings, not guarantees. Fragmentation, sliver triangles, and open/non-manifold
regions remain possible. Back up `.blend` files before testing.
