# Remi 2.7.0-beta.20 — Reliable Cloud Downloads

- Download up to three shared assets simultaneously. A slow or failed card no
  longer holds the remaining cards behind it.
- Generated-file tickets resolve in the download queue, keeping board loading
  and project controls responsive.
- Cards show queued, downloading, verifying, retrying, and failed states.
  **Retry Download** fetches the existing file without starting another job.
- Downloads stream into temporary files and verify original size and SHA-256
  before becoming ready. Complete cached files are reused after restart.
- Windows status-file locks are retried, and local update errors keep the Cloud
  timer running. A stalled sync connection produces a visible error.

Requires Blender 5.3 or newer. Install the ZIP for your platform and restart
Blender to load the updated download worker.
