# 2.7.0-beta.3 — whole-mesh octree ray baking

Local development prerelease; retain the Create Mesh changes from beta.2.

- With a low-poly mesh active and **no drawn area**, offer **Bake Whole Mesh ·
  Octree** in Texture. Keep the explicit Project from View/lasso layer workflow.
- Build a sparse hierarchy of full anisotropic Gaussian supports. Trace and refine
  first hits of a configurable Gaussian density surface around every UV texel.
- Bake source color and density-gradient normals directly from the Gaussians,
  without sampling reconstructed-mesh shading normals. Preserve target vertex count.
- Use Blender's exported tangent basis and mirrored handedness for normal maps.
- Report hits, misses, cage clipping, and step-budget exhaustion. Filled colors
  do not gain confidence. Keep legacy surface sampling and Keep Baked available.
- Use existing external numpy/scipy/Pillow dependencies; no new downloads or
  native reconstruction-tool requirement for the texture bake.

This is a density-surface hypothesis, not native 3DGS alpha rendering or a promise
of clean ground-truth normals. Very low-poly targets cannot recover silhouette or
missing geometry through texture maps. Source and target must align in world space.

See [Texture workflow and controls](../texture_projection.md).
