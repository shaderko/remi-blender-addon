# 2.7.0-beta.5 — local-layer appearance and packed rebake fix

- Fix rebaking onto packed images: load fresh color/normal datablocks instead
  of changing an existing packed image's path and reloading its old pixels.
  Keep previous packed/painted images untouched. Apply the same fix to view layers.
- Replace the default exterior first-density-hit bake with an octree-accelerated
  local Gaussian compositor. Match the source layer nearest each target texel,
  then alpha-composite only its depth neighborhood. Unrelated foreground parts
  outside that neighborhood no longer cover the intended layer.
- Add **Maximum Source Gap** (2% default) and **Layer Width** (0.5% default).
  Distances are fractions of the Gaussian support-bounds diagonal. Excessive
  values can still match the wrong nearby part.
- Replace default density-gradient normals with confidence-weighted local
  source-depth plane fits and a clean-geometric-normal fallback. **Clean Geometry
  Only** disables estimated Gaussian detail. Respect Blender's exported shading
  frame, tangent basis, mirrored transforms, and existing authored normal maps.
- Keep missing source evidence explicit: neutral color, clean geometry normals,
  zero confidence, and at most two pixels of same-island hole filling.
- Retain **Density Surface (Legacy)** for reproducing old bakes, **Surface Sampling
  (Legacy)**, and the existing view/lasso projection workflow.
- Keep optional external Numba acceleration, eight CPU threads, 32K-ray batches,
  cancellation, and a reported NumPy reference fallback. No automatic installs.

On the saved local character (262,144 Gaussians, 8,103 triangles, 659,969 UV rays
at 1K), the corrected worker matched 655,760 texels, leaving 4,209 unmatched
instead of 72,373. The saved-scene rebake took about 6.5 seconds, preserved all
4,058 vertices, and both packed maps exactly matched their fresh PNGs.
These are one-machine diagnostics, not a quality/performance guarantee.

**Restart Blender and run a fresh bake after updating.** Existing materials
still contain their old packed pixels; upgrading alone does not replace them.
Choose the correct **Splat Source** if an older optimized mesh has lost its link.

This transfers existing local Gaussian evidence; it cannot invent unseen
appearance, reconstruct missing geometry, or recover a true PBR material. A
relit Principled material will not exactly match the unlit Gaussian render.
The local compositor approximates appearance; it is not Blender's native
screen-space 3DGS renderer or a complete multiview visibility solver.

See [texture projection](../texture_projection.md) for setup and controls.
