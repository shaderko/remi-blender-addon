# 2.7.0-beta.6 — opacity iso-surface mesh backend

- Replace the mesh reconstruction backend with **remi-splat-mesh**
  (<https://github.com/shaderko/remi-splat-mesh>, pinned git tag). Each splat
  contributes its anisotropic Gaussian to a voxel field; the mesh is the
  iso-surface of the accumulated opacity field, cleaned of sub-threshold
  components and Taubin-smoothed. Output is closed and manifold by construction.
- Remove the camera-aware silhouette pipeline, the vendored Modly surface-nets
  mesher, and the optional Spirula surface tool. **Create Mesh** now has one
  path and no external binary.
- Remove the **Mesh Backend** selector, **Surface Tool Folder**, and
  **Install Surface Tool**: there is nothing to choose or install. Older .blend
  files that stored those settings load normally; the properties are gone.
- Create Mesh no longer requires Windows x64. The worker runs on CPU, or on CUDA
  when torch is available in the external Python.
- Faster: 512³ extraction is about 10 s on a GPU and 31 s on CPU, down from
  roughly four minutes. 256³ is about 4.5 s.
- Report topology: triangle/vertex counts, components, boundary and non-manifold
  edge counts, plus component warnings. Component removal is reported, never
  silent.

## Setup

The external Python selected in Generation Settings must have the backend:

```
pip install -r integrations/splat_mesh/requirements-splatmesh.txt
```

That installs `remi-splat-mesh` and its dependencies (`numpy`, `scipy`,
`scikit-image`). Torch is optional and only used to accelerate the field build.

## Breaking changes

- `remi.install_surface_tool` no longer exists.
- `integrations/splat_mesh/remi_surface/`, `vendor/`, `worker.py`,
  `density_worker.py` and `render_views.py` are deleted.
- `MeshJob.start()` takes `python`, `archive`, `output`, `quality`, `source`.

Mesh quality remains **Dense** (512³) and **Fast** (256³).
