# 2.7.0-beta.7 — Remi Board and native Blender editing

The new image → 3D source → mesh workflow is part of the normal installable
add-on. No development checkout, `.bat` launcher, or Python launch script is
needed. This is a prerelease; keep backups of your projects and asset folders.

## Install

- **Blender 5.3 only.** This beta ships a Windows x64 ZIP, tested with Blender
  5.3 beta. Blender 5.1/5.2 and other platforms are not validated for this build.
- Install the ZIP through **Preferences → Get Extensions → Install from Disk**
  and enable Remi. Do not extract it into `scripts/addons` or install a duplicate
  legacy copy. Close a development-launcher Blender before installing normally.
- Open **N → Remi → Open Remi Board**, **View → Open Remi Board**, the viewport
  header's **Remi Board** button, or search **Open Remi Board** with `F3`.
- Enabling Remi preserves the current workspace. The board opens beside a
  viewport in its own workspace, leaving the original Layout intact. A saved
  board workspace resumes when its `.blend` is reopened.

## Board workflow

- Freely arrange Image, Gaussian source, Mesh, and result cards. Select, group
  move, box-select, drop multiple images, and middle-drag anywhere to pan.
- A fixed, transparent left toolbar replaces the changing bottom action buttons:
  Generate 3D, Create Mesh, Run Remi Flow, Texture Mesh, Edit in Blender,
  Add to Scene, Add Images, Export Asset, and Cancel Job.
- Left-click runs saved settings. Right-click generation, meshing, flow, or
  texturing icons configures defaults without starting work, even when the
  action is disabled. Each queued job retains its settings snapshot.
- The bottom composer always offers Create Image. Secondary actions and
  confirmed multi-selection file deletion remain in card context menus.
- Local automatic jobs produce separate result cards/files, preserve their
  sources, and never import results into the working scene automatically.
  Add to Scene remains explicit. Interrupted jobs are not silently replayed.

## Native previews and editing

- Gaussian cards use Blender 5.3's native renderer. Mesh cards have the same
  interactive in-card viewport, including vertex colors, materials, textures,
  and multipart meshes. **Alt-drag** to orbit; reset to Front from the card menu.
- Mesh and Gaussian previews share a limit of **three loaded models** and unload
  after **30 seconds idle**. The last view remains as a cached PNG thumbnail.
  Temporary preview resources are removed before saving the project.
- Edit in Blender opens each mesh in its own ordinary scene with normal Blender
  tools and Undo, using a shared Mesh Editor workspace. No Remi session starts
  automatically, and the original scene remains unchanged.
- Apply to Card updates the **same card**, retaining identity, arrangement,
  connections, and previous files as revisions. Mesh parts, evaluated modifiers,
  UVs, and GLB-compatible textures are exported. Existing scene instances are
  not replaced. Back to Board keeps the edit available to resume.
- Apply to Card and Back to Board live in the viewport header. The old sidebar
  Generate tab is removed; native Optimize and Texture tools remain available.

## Texture transfer

- Drag the body of a Gaussian source card onto a ready Mesh card to queue a
  local albedo-and-normal bake as a new textured GLB. The source returns to its
  original position; inputs and the working scene remain unchanged.
- Target highlights, travelling particles, a scanning loader, real worker
  status, and completion feedback show the transfer. Missing UVs are generated.
- Ctrl-drag is move-only; Esc cancels the highlighted drop. Repeated identical
  drops select an existing queued/running bake instead of duplicating it.
- Optional handle-based appearance links and toolbar-based texturing remain.

## Setup and limitations

AI generation still requires the external CUDA/PyTorch environment and
downloaded model weights. They are not bundled in the add-on. Configure runtime
paths in the board settings; existing configured paths remain usable.
Create Mesh uses the external `remi-splat-mesh` backend introduced in beta.6.

Keep source/output folders alongside the `.blend`: the board records file
references and lineage, not packed copies of every asset. Instant Meshes'
retopology algorithm is unchanged in this release; adaptive quad density is a
separate proposed follow-up, not a feature of this beta.
